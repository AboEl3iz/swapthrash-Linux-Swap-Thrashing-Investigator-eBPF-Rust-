libbpf_rs

Module query 

Source
Expand description

Query the host about BPF

For example, to list the name of every bpf program running on the system:

use libbpf_rs::query::ProgInfoIter;

let mut iter = ProgInfoIter::default();
for prog in iter {
    println!("{}", prog.name.to_string_lossy());
}
