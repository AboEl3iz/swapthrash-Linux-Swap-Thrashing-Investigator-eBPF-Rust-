pub fn assoc_struct_ops(&self, map: &Map<'_>) -> Result<()>

Associate this program with a struct_ops map.

This allows a non-struct_ops BPF program to be used as a callback implementation within a struct_ops map. Both the program and map must be loaded.

This program must not be of type ProgramType::StructOps, and the map must be of type MapType::StructOps.
